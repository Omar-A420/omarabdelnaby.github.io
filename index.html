Problem Overview

Given an undirected graph G=(V,E) and integer k, decide whether there is a set S subset V with |S| <= k such that every edge touches at least one selected vertex.

1. Vertex Cover Is In NP

  • Certificate: a proposed set S of vertices.
  • Check |S| <= k.
  • For every edge (u,v), verify that u in S or v in S.
  • The verifier scans the edge list once, so verification time is O(E).

Reduction From 3-SAT

  • For each variable xi, create two vertices xi and not xi connected by an edge.
  • For each clause, create a triangle of its three literal vertices.
  • Connect every clause literal to the matching variable literal vertex.
  • Set k = n + 2m, where n is variables and m is clauses.

Concrete 3-SAT Example

For the formula (x1 OR !x2 OR x3) AND (!x1 OR x2 OR !x3), there are n = 3 variables and m = 2 clauses. The reduction creates 3 variable gadgets and 2 clause gadgets, so k = n + 2m = 3 + 4 = 7.

Correctness: Forward Direction

If the 3-SAT formula is satisfiable, choose one vertex from each variable gadget according to the truth assignment. For every clause triangle, at least one literal is true; choose the other two triangle vertices so all three triangle edges and literal connection edges are covered. The cover has exactly n + 2m vertices.

Correctness: Backward Direction

If the graph has a vertex cover of size n + 2m, every variable edge contributes at least one chosen vertex and every clause triangle contributes at least two chosen vertices. The one unchosen literal in each triangle must have its connection edge covered by the matching variable literal, which defines a satisfying assignment.

Polynomial-Time Construction

The construction creates two vertices per variable, three vertices and three internal edges per clause, plus one literal connection per clause occurrence. This is O(n + m) vertices and edges, so the reduction runs in polynomial time. This proves 3-SAT ≤p Vertex Cover. Since 3-SAT is NP-complete and Vertex Cover is in NP, Vertex Cover is NP-complete.

Brute Force vs Greedy

Brute force is exact because it tests subsets of vertices until it finds the smallest cover. Greedy is fast because each iteration commits to both endpoints of an uncovered edge, but that local choice can be larger than optimal.

Takeaway

  • Exact algorithms are valuable for proof and small inputs.
  • Approximation algorithms trade optimality for speed and a mathematical quality bound.
  • For Vertex Cover, the greedy matching-based method gives a clean 2-approximation.

Design Paradigm: Greedy

The algorithm repeatedly makes an irreversible local choice: pick any uncovered edge (u,v) and add both endpoints to the cover.

Why The Choice Makes Progress

Adding both endpoints immediately covers the selected edge and every edge incident to either endpoint. Therefore each iteration strictly reduces the set of uncovered edges until none remain.

Approximation Quality

The selected uncovered edges are disjoint in the sense that after an edge is chosen, all incident edges are marked covered. These chosen edges form a matching. Any vertex cover must include at least one endpoint from each matching edge, while greedy includes exactly two, so |Cgreedy| <= 2 * |Coptimal|.

Counterexample

For a star graph with edges A-B, A-C, A-D, A-E, optimal chooses only {A}. If greedy first chooses edge A-B, it adds {A,B}, producing a larger cover.

Simple Definition

A vertex cover is a set of vertices that touches every edge. If an edge has at least one endpoint inside the selected set, that edge is covered.

Applications

  • Network security: place monitors on machines so every connection is observed.
  • Monitoring connections: select checkpoints that cover all links.
  • Bioinformatics: model protein interaction coverage.
  • VLSI design: select components or pins that cover circuit connections.

Worked Example

Graph edges: A-B, A-C, B-D, C-D, D-E and k = 2.

  • Brute force finds the minimum cover {A, D}. Every edge touches A or D, so the decision answer for k=2 is YES.
  • Greedy might pick A-B, add A and B, then later pick C-D, add C and D, giving {A,B,C,D}.
  • The greedy cover is valid but larger. Its ratio is 4 / 2 = 2, still within the guaranteed bound.
